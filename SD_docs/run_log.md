
#תיעוד תהליך התקנת הפרויקט:
מה עבד?
הרצתי את  הפקודות כדרישת המטלה 
npm install
npm run dev
ועתכנית עבדה והשרת רץ
היה לי חבילות שלא עבדו 
והרצתי
 npm audit
 ועדין לא עבד הותקנו בהצלחה אז הרצתי:
 npm audit fix --force
 וכל החבילות ב"ה הותקנו בהצלחה והפרויקט רץ
 -npm test-עבד בהצלחה 
 -npm run typecheck-עבד בהצלחה
 -npm run dev-רץ כמו ליפני
